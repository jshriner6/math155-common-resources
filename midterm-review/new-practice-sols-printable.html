    3.

    Find the horizontal asymptote(s) of \(\displaystyle f(x) = \frac{3e^{-x}+ x^{-2}- 2x^{2}}{x+e^{-x}+x^{4}}\) using the method of leading behaviors.
    🔗
    Solution.
    \(\displaystyle \lim_{x\to \infty} f(x) = \lim_{x\to \infty} \frac{-2x^2}{x^4}=0 \)
    🔗
    \(\displaystyle \lim_{x\to -\infty} f(x) = \lim_{x\to -\infty} \frac{3e^{-x}}{e^{-x}}=3 \)

        🔗

      3. \(\displaystyle \displaystyle \lim_{x \to 0}\frac{\ln(1-x)}{x}\)
        🔗

      4. \(\displaystyle \displaystyle \lim_{x \to \infty}\frac{\sin(x)}{x}\)

    Solution.
    LH Rule does not apply to \(\lim_{x \to 1} \frac{2^x}{3^x}\) and \(\lim_{x \to \infty} \frac{\sin(x)}{x}\text{.}\)
    🔗
    \(\displaystyle \lim_{x \to 1}\frac{2^x-2}{3^x-3} = \lim_{x\to 1} \frac{\ln(2)2^x}{\ln(3)3^x}= \frac{2\ln(2)}{3\ln(3)}\)
    🔗
    \(\displaystyle \lim_{x \to 0}\frac{\ln(1-x)}{x} = \lim_{x\to 0} \frac{-1}{1-x}= -1\)
    🔗
    \(\displaystyle \lim_{x \to \infty}\frac{\ln(x)}{\sqrt{x}} = \lim_{x\to \infty} \frac{x^{-1}}{0.5x^{-1/2}}= \lim_{x\to \infty} \frac{2}{x^{1/2}}=0\)

    6.

    Evaluate the following integrals using substitution.
    🔗
    1. \(\displaystyle \displaystyle \int (\cos(x))^{5}\sin(x) dx\)
      🔗
      🔗
    2. \(\displaystyle \displaystyle \int_{2}^{5} \frac{1}{x\ln(x)}dx\)
      🔗
      🔗
    🔗
    Solution.
    1. Choosing \(u = \cos(x)\) and substituting, you should obtain
      \begin{equation*} \int -u^5 \quad du = -1/6u^6 + C = -1/6(\cos(x))^6 + C \end{equation*}
      🔗
      🔗
    2. Choosing \(u=\ln(x)\) and substituting, you should obtain
      \begin{equation*} \int_{\ln(x)}^{\ln(5)} \frac{1}{u}du = \ln(\ln(5)) -\ln(\ln(2)) \end{equation*}

    8.

    A particle moves in a straight line and has acceleration given by \(a(t) = 6t + 4\) cm/\(\mathrm{s}^{2}\text{.}\) Its initial velocity is \(v(0) = -6\) cm/s and its initial displacement is \(s(0) = 9\) cm. Find its position function \(s(t).\)
    🔗
    Solution.
    \(a(t) = 6t + 4\)
    🔗
    \(v(t) = 3t^2+ 4t - 6\)
    🔗
    \(s(t) = t^3+ 2t^2 - 6t+9\)

    3. If the units of \(F'(x)\) are liters per second, what are the units of \(\int_{0}^{10}F'(x) dx\text{?}\)
      🔗
      🔗
    🔗
    Solution.

    \(2\) \(9\)
    \(4\) \(11\)
    \(6\) \(11\)

    🔗
    We cannot easily compute the value of \(F(x)\text{,}\) since we only have a table of \(5\) values, and cannot compute \(\int_0^{10} F(x) \quad dx\) exactly. We can compute the average value of \(F'(x)\text{,}\) which is \(1/10 \int_0^{10} F'(x) \quad dx = 1/5\text{.}\)
